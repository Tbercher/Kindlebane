# Guide
# Look for the highlighted character and select one of the abilities on the bottom row. Then select an enemy and confirm the attack. You will see the healthbar decline. Kill all the enemies or survive until the bonfire is lit indicated by bar at the top of the screen.

## Documentation

Run `python tools/generate_docs.py` to generate the reference pages from
`/// @doc-...` markers in `objects/obj_gameInfo/Create_0.gml`. The generator
documents values as written or resolved without validating game balance. It
warns about missing sprite images, missing parent sections, and circular
references while generating the available documentation.
